# GRAGの学習不調に関する調査

## 調査結果

現在のGRAGでは、対照学習によるQ値を使ってPPOの方策を更新すると、座標にかかわらず同じ方向を選び、壁に衝突し続ける現象が確認された。診断用に行動の評価値を最短経路に基づく値に置き換えると、同じActorとPPO更新でも位置によって方向を切り替えられた。対照Qによる行動の順位付けと、そこからActorを更新する過程が調査対象である。

## 保存された学習記録

6×6マップのGRAGの保存記録は1,446エピソード、309,702ステップ、累計成功510回だった。直近100エピソードの成功率は0%、平均ステップ数は上限の300だった。最終エピソードは300歩中295歩が衝突だった。

別の保存済み再生では、開始地点 `[5, 0]` から右へ移動して `[5, 5]` に到達した後、同じく右を選び続けて295回衝突した。保存結果にはGRAGのモデルチェックポイントが含まれていないため、これらの実行の学習済み重み自体は解析していない。

## 比較実験

同じ6×6マップ、最大300ステップ／エピソード、seed 42・7・19で、各条件8,192ステップ学習した。ゴール以外の31マスについて、Actorの最大確率行動が壁を考慮した最短距離を1歩短くするマスの数を数えた。

| seed | 現行の対照Q | 初回の対照学習までPPOを待機 | 診断用の最短距離に基づく行動評価 |
| --- | --- | --- | --- |
| 42 | 21/31、全マスで上 | 21/31、全マスで上 | 30/31 |
| 7 | 1/31、全マスで左 | 1/31、全マスで左 | 30/31 |
| 19 | 21/31、全マスで上 | 21/31、全マスで上 | 30/31 |

最短距離に基づく条件では、診断のためPPOが使う各行動のQ値を、その行動の遷移先からゴールまでの最短距離の負値に置き換えた。最短距離は環境の遷移から計算している。この条件は学習アルゴリズムの性能比較ではなく、行動評価が与えられた場合にActorが位置依存の方策を表現・学習できるかを調べるための対照実験である。

seed 42の現行条件では、対照Qが最短距離を短くする行動を最大としたマスは、4,096ステップ時点の23/31から8,192ステップ時点の14/31になった。初回の対照学習までPPO更新を待つ条件でも3 seedで方策の一方向への偏りが残った。

学習後、壁と現在位置を固定してゴールを右上から左下に変更した場合、現行Actorの最大確率行動は、比較可能な30マスすべてで変わらなかった。この検査は固定ゴールで学習した方策に未学習のゴールを与えたものである。

## 実装から考えられる要因

- 現在位置は観測の3チャネル目に入力される。位置情報が欠落しているのではなく、位置ごとに異なる行動を選ぶ方策が十分に学習されていない。
- 対照学習の正例は同一エピソードで実際に到達した将来地点であり、PPOは指定された最終ゴールに対するQ値を用いる。成功が少ない場合、最終ゴールへの行動価値が十分に学習されない可能性がある。
- 衝突すると位置は変わらないが、現在の対照損失とPPO更新は衝突情報や保存された報酬を直接使わない。壁際で同じ行動を繰り返すと、その地点が将来到達地点に繰り返し現れる。
- 別エピソードの到達地点は負例となるため、同じ座標が別エピソードから負例として選ばれる場合がある。その影響は今回の実験では個別に検証していない。
- 通常のPPOは報酬からGAEを計算する。現在のGRAGは対照Qの行動ごとの差をadvantageとして使うため、Q値の行動順位が方策更新に直接影響する。

これらは実装と実験結果に基づく要因候補であり、負例の選択、軌跡の偏り、Q値の近似誤差それぞれの因果的な寄与は切り分けていない。

## 再現

ワークスペースのルートから、環境変数 `PYTHONPATH=GridWorld;.` を設定して次を実行する。

```powershell
$env:PYTHONPATH = 'GridWorld;.'
python tmp/diagnose_grag_critic.py 42 learned
python tmp/diagnose_grag_critic.py 42 warmup
python tmp/diagnose_grag_critic.py 42 oracle
```

実験は `GridWorld/data/world.json` のマップを読み込む。`learned` は現行実装、`warmup` は最初の対照学習までPPO更新を待つ条件、`oracle` は最短距離による診断条件である。
